# United Papers — B2B demo

Wholesale foodservice packaging storefront + operations portal (synthetic demo data).
See [docs/DEMO_RUNBOOK.md](docs/DEMO_RUNBOOK.md) to run it, [docs/DEMO_STATUS.md](docs/DEMO_STATUS.md) for status, [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for design.

Quick start: `npm install` · `npm run setup:env` · `npm run db:start` (keep open) · `npm run db:migrate` · `npm run db:seed` · `npm run build` · `npm start`.
